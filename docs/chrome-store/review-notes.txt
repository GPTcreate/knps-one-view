Chrome 웹스토어 심사 설명 초안

단일 목적
사용자가 로그인한 숲나들e 공식 월별 조회 화면의 객실별 빈자리와 다음 예약대기 신청 가능 순위를 여러 휴양림에 걸쳐 비교합니다.

권한 설명
storage: 조회한 객실 상태, 원천 관측 시각, 연결한 공식 탭의 숫자 ID와 작업 진행 상태를 기기 안에 보존합니다. 서비스 워커가 재시작되어도 진행과 취소 상태를 잃지 않기 위해 필요합니다.
https://www.foresttrip.go.kr/*: 공식 월별 조회 탭을 찾아 연결하고, 해당 페이지에 선언된 콘텐츠 스크립트가 일반 검색 조건 변경과 검색 버튼 클릭을 수행해 화면의 객실 표를 읽습니다. 콘텐츠 스크립트 실행 경로는 /rep/or/sssn/monthRsrvtStatus.do로 제한됩니다.
tabs·cookies·history·scripting·webRequest·all_urls 권한은 요청하지 않습니다.

데이터 처리 공개
공식 페이지의 객실명·객실 정보·날짜별 예약 상태라는 웹사이트 콘텐츠와 사용자가 선택한 검색 조건을 로컬 처리합니다. 해당 항목을 처리하지 않는다고 일괄 체크하지 않습니다.
원격 개발자 서버 전송, 광고·분석 SDK, 계정·인증·결제·건강 데이터 처리는 없습니다. 쿠키를 복사하거나 로그인 요청을 우회하지 않습니다.
공식 사이트는 일반적인 로그인·검색 요청을 받습니다. 확장 로컬 저장소와 확장 화면 localStorage를 사용하며 Chrome sync는 사용하지 않습니다.
제출 직전 개발자 대시보드의 최신 분류와 코드·개인정보 안내의 일치 여부를 확인합니다.

원격 코드
없음. 모든 JavaScript와 공식 시설 목록은 ZIP 안에 포함됩니다. eval·원격 스크립트·외부 라이브러리 실행은 없습니다.

테스트 절차
1. 확장 아이콘으로 자체 대시보드를 엽니다. 별도 Python·localhost 서버를 실행하지 않습니다.
2. ‘숲나들e 연결’을 누르고 공식 사이트의 일반 로그인 절차를 진행합니다. 실계정 비밀번호나 쿠키를 제출 자료에 넣지 않습니다.
3. 숲자리로 돌아와 지역(처음에는 제주)·지원되는 날짜를 선택해 검색합니다.
4. 공식 화면의 검색만 수행하며 예약·대기 신청·결제 버튼은 누르지 않는 것을 확인합니다.
5. 다른 날짜 이동, 빈자리/예약대기 필터, 조회 중단, 조회 기록 삭제를 확인합니다.
6. 로그인되지 않았거나 공식 사이트가 지연되면 미확인/중단으로 처리하는 것을 확인합니다.
심사자가 로그인을 진행할 수 없는 경우 비로그인 시설 탐색은 가능하지만 실제 월별 현황 수집은 제한됩니다. 심사용 가짜 빈자리나 숨겨진 우회 모드는 제공하지 않습니다.

검증 상태
기존 개발 연결 도구로 제주 4곳·89객실 실조회 증거가 있습니다. 새 독립 패키지는 자동 검증과 별도로 실제 Chrome 설치 검증을 완료한 뒤 그 결과를 이 문서에 추가해야 합니다.
