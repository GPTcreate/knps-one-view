이름
숲자리 · 휴양림 빈자리와 예약대기 비교

짧은 소개
숲나들e 공식 화면에서 여러 자연휴양림의 1박 빈자리와 대기 신청 가능 순위를 비교합니다. 예약·결제는 공식 사이트에서 직접 진행합니다.

상세 설명
휴양림마다 달력을 따로 열어 빈자리와 예약대기를 찾기 번거로우셨나요?
숲자리는 사용자가 로그인한 숲나들e의 공식 월별 현황을 조회해 여러 시설의 숙박 기회를 비교하는 Chrome 확장입니다.

• 지역·체크인 날짜·인원으로 1박 기준 탐색
• 여러 휴양림의 빈자리와 예약대기 신청 기회 비교
• 날짜 띠를 눌러 다른 날짜로 이동
• 저장한 시설, 이름·운영 구분·상태 필터, 목록·표 보기
• 객실별 공식 표시와 다음 대기 신청 가능 순위 확인
• 확인 시각과 미확인·만료·매진·휴무·우선예약·추첨 구분
• 조회 중단과 기기에 저장된 조회 기록 삭제

사용 방법
1. 설치 후 확장 아이콘을 눌러 숲자리를 엽니다.
2. ‘숲나들e 연결’을 누르고 열린 공식 사이트에서 직접 로그인합니다.
3. 연결 탭을 열어 두고 숲자리로 돌아와 지역·날짜를 검색합니다.
4. 조회 중에는 공식 탭의 조건을 직접 바꾸지 마세요. 완료된 결과부터 비교할 수 있습니다.

Python 설치나 별도 로컬 서버가 필요하지 않습니다.
로그인 쿠키·비밀번호·개인 예약 내역을 읽지 않으며 개발자 서버로 조회 결과를 전송하지 않습니다.
예약 신청·대기 신청·결제를 자동 수행하지 않습니다.
표시된 대기순위는 다음 신청 가능 순위이며 사용자의 개인 대기순번이 아닙니다.
공식 사이트의 로그인·조회 가능 기간·운영 상태에 따라 결과가 달라질 수 있으며, 미조회·실패 자료는 미확인으로 표시합니다.

숲자리는 산림청·숲나들e와 별개의 비공식 도구입니다.
별도의 웹 버전은 공식 API 연계를 준비하고 있으며, 이 확장의 설치만으로 동작하는 조회 방식과 구분됩니다.
