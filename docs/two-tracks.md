# 숲자리 두 가지 제품 · 2026-10-18

| 항목 | 웹 버전 | Chrome 확장 버전 |
| --- | --- | --- |
| 사용자 설치 | 없음 | Chrome 웹스토어에서 확장 설치 |
| 실행 | 웹사이트 접속 | 확장 아이콘 → 자체 비교 화면 |
| 휴양림 현황 | 운영자 공유 관측·중복 제거 갱신 대기열, 공식 API 연계는 승인 대기 | 사용자가 로그인한 숲나들e 월별 화면을 직접 조회 |
| Python·로컬 서버 | 운영자가 서버 실행, 방문자는 불필요 | 불필요 |
| 현재 상태 | 공유 관측 반영까지 로컬 시험 구현, 외부 공개 전 | 독립 MV3 패키지·자동 검증 완료, 새 패키지 실설치 검증 대기 |
| 출시 조건 | 공유·재제공 허용 확인, 실조회 대조와 HTTPS 운영 배포. API 경로는 승인 후 연계 | 개발자 등록, 실설치 검증, 지원 연락처·공개 개인정보 안내 URL·실제 화면 이미지 확정, 웹스토어 심사 |

두 제품이 같은 데이터 규칙·화면을 공유한다. 웹 방문자에게 확장 설치나 숲나들e 로그인 연결을 요구하지 않는다.
확장은 숲나들e에 사용자가 직접 로그인하며, Python·localhost·연결 키를 사용하지 않는다.
과거 `browser-bridge/`는 로컬 개발 검증 도구다. 웹스토어에 제출하는 제품은 `extension/`의 소스와 `build_extension.py`로 만든 독립 패키지다.
`operator/`와 `build_operator.py`는 서비스 운영자용 별도 수집기다. 인증된 고정 서버로 관측 결과를 보내며 일반 사용자에게 배포하거나 개인용 스토어 패키지와 섞지 않는다. [운영자 가이드](operator-guide.md).

## 검증 구분

2026-10-17 Chrome에서 확인한 제주 4곳·89객실 연속 조회는 기존 로컬 개발 연결 도구의 증거다.
새 독립 확장은 같은 공식 표 추출기를 사용하되 저장·작업 관리·화면 통신 구조가 다르다. 기존 검증을 새 패키지의 실설치 검증으로 대체하지 않는다.
새 저장소·탭 결합·작업 복구·취소·데이터 삭제·모의 2시설 조회와 대시보드 통신은 자동 검증한다.

## 상태 판정

‘Chrome 웹스토어 정식 출시’는 심사 통과 후 실제 스토어 URL이 생긴 상태를 뜻한다. ZIP 준비나 개발자 모드 설치를 정식 출시로 부르지 않는다.
‘웹 휴양림 현황 제공 완료’는 제공 권한이 확인된 데이터 경로와 실제 잔여·대기 관측을 운영 서버에서 검증한 상태를 뜻한다. 운영자 관측과 승인 API는 출처·가동 범위를 구분한다. 시설 목록과 과거 예약 통계 API로 잔여 현황을 대신하지 않는다.
