# 공식 휴양림 API 조사 · 2026-10-18

## 확인된 경로

디지털서비스 개방 포털의 ‘수시신청’ 27개 서비스 중 ‘휴양림 예약 / 국립자연휴양림관리소’가 있다.
해당 상세 창은 전국 휴양림 조회·이용 예약·휴양림별 잔여 현황 조회를 설명한다.
상세 창의 신청 자격은 아래 중 하나 이상을 취득하도록 안내한다.

- ISMS-P
- 공인전자문서중계자
- 본인확인기관
- 본인신용정보관리업자

현재 신청 주체의 자격·기존 승인·인증키는 확보하지 않았다. 공개된 안내만으로 조회 전용 서비스의 자격 면제를 확정하지 않는다.
공립·사립 포함 범위, 날짜별 잔여 수량과 대기 신청 가능 순위 필드, 대량 비교 조회 허용량은 별도 확인 대상이다.
소개 페이지의 휴양림 개소 수는 과거 안내일 수 있으므로 현재 목록 수나 지원 범위의 근거로 사용하지 않는다.

## 신청과 인증키

수시신청은 분기별 심의 방식이다. 안내상 2·5·8·11월 말 접수 마감, 익월 심의 및 결과 안내.
문서24로 공문을 제출하며 수신처는 행정안전부 공공서비스혁신과다.
수요기관 신청서, 개인정보 수집이용 동의서, 서비스별 이용계획서, 사업자등록증 및 최근 법인등기사항증명서 등이 필요하다.
지원센터 절차는 선정·협의 → 이용약관 체결 → 검증서비스 신청/승인 → 개발/연계 테스트 → 운영 API 인증키 발급/운영 전환 순서다.
지원센터 안내 연락처: susi@vtw.co.kr / 1551-0627. 발송·전화 문의는 아직 수행하지 않았다.

공식 HWP 원본 3개를 `official-forms/`에 내려받아 원본 형식을 확인했다. 회사 정보·직인·서명을 임의로 작성하지 않았다.
문의 초안은 `inquiry.txt`, 조회 전용 이용계획 초안은 `usage-plan.txt`다.

## 일반 공공데이터 API

공공데이터포털 ‘산림청_국립자연휴양림 예약정보’(15134227)는 현재 설명상 2023-03-15~2024-02-28의 과거 예약 현황이다.
현재 빈자리·다음 대기 신청 순위를 제공하는 API라고 단정할 수 없으며 실시간 화면에 연결하지 않았다.
숲나들e 홈페이지에서 사용되는 내부 요청과 정식 외부 연계 API도 구분한다. 로그인 요구를 우회하거나 웹사이트 내부 경로를 공개 API로 포장하지 않는다.
