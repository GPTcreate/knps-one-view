제목: 휴양림 잔여현황 조회 전용 서비스의 API 연계 자격 및 제공 범위 문의
수신 예정: 디지털서비스개방 수시신청 지원센터 (susi@vtw.co.kr)
상태: 검토용 초안 / 미발송

안녕하세요. 여러 자연휴양림의 1박 잔여 객실과 예약대기 신청 기회를 한 화면에서 비교하는 ‘숲자리’ 서비스를 검토하고 있습니다.

서비스에서 예약·결제·본인 확인·개인 예약 내역 조회는 수행하지 않고, 시설·객실별 공개 예약 가능 상태와 다음 대기 신청 가능 순위만 조회하려고 합니다. 예약과 대기 신청은 숲나들e 공식 사이트로 이동해 사용자가 직접 진행하는 방식입니다.

수시신청 안내의 휴양림 예약 서비스 자격 요건을 확인하였으며, 현재 아래 인증 자격이나 기존 연계 승인은 보유하고 있지 않습니다. 조회 전용 범위에 대해 다음 사항을 문의드립니다.

1. 개인정보·CI를 취급하지 않는 잔여현황 조회 전용 서비스도 ISMS-P 등 열거된 자격 중 하나가 반드시 필요한지요? 별도 데이터 제공·조회 전용 API·협약 경로가 있는지요?
2. 날짜별 시설·객실 목록, 실제 예약 가능 수량 또는 상태, 다음 대기 신청 가능 순위(예: 대1·대2·대3)를 제공받을 수 있는지요?
3. 국립 외 공립·사립 휴양림도 제공 대상에 포함되는지요?
4. 여러 시설을 한 번에 비교하기 위한 조회·캐시·재배포 허용 조건, 갱신 주기, 호출 한도는 어떻게 되는지요?
5. 조회만 제공하는 소규모 서비스가 신청할 수 있는 검증환경과 신청 절차, 필요 서류, 비용이 있는지요?
6. API 명세와 샘플 응답, 장애/만료 처리 기준을 받을 수 있는지요?
7. 정식 API 승인 전 운영자가 자신의 로그인된 공식 월별 화면을 일반 검색 조작으로 조회하고, 계정·쿠키·개인 예약 내역 없이 시설·객실·날짜·예약 상태·다음 대기 신청 순위·관측 시각만 저장해 다른 웹 방문자에게 제공하는 방식이 허용되는지요? 허용된다면 별도 동의·협약·수집 간격·보관 기간·출처 표기 조건이 있는지요?
