- 웹에서 설치·로그인·확장 작업 대기열을 요구하지 않는 흐름과 기본 서버의 개발 연결 API 비활성화
- 새 독립 확장의 기기 저장, 발신 탭 결합, 중복 수신, 조기 완료 거절, 취소·삭제 후 지연 응답 거절
- 서비스 워커 재생성 후 진행 보존, 연결 탭 닫힘 시 중단, 자체 화면 재사용, 큰 관측값의 저장 한도 처리
- 새 확장 콘텐츠 스크립트의 모의 2시설 조회·취소. 쿠키 접근 시 테스트 실패, 예약 버튼 클릭 0회
