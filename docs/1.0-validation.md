# 1.0 검증 결과

2026-10-17 기준. 사용자가 연결 도구 설치와 로그인을 마친 후 Chrome 실제 연속 수집 검증을 완료했다.
기획·화면·개발·회귀 검증·실행기·압축본과 실제 연동 검증 결과를 반영해 최종 1.0으로 표시한다.

## 자동 검증

- Node 37개 PASS: 상태·날짜·인원·정원·만료·알림, 전체 앱 DOM, 검색 경합, 입력/링크 처리, 공식 모양 월별 표, 2개 시설 연결 흐름 모의 검증, 취소, 중계 접근 범위, 연결 직후 첫 검색.
- Python 27개 PASS: 수집 파싱, 전체/부분 실패 보존, 원자적 저장 실패 복구, 날짜별 시각, 서버 호스트·출처·파일 접근 제한, 중복 수신, 조기 완료 거절, 손상된 휴양림 파일의 국립공원 영향 격리, 실행기·공개 목록 갱신기.
- JavaScript 5개 파일 문법 검사 PASS, Prettier 서식 검사 PASS, Python 실행 모듈 컴파일 PASS.
- 모의 검증은 실제 Chrome 확장 설치·로그인·NetFunnel·여러 시설 응답 시간을 검증한 것으로 간주하지 않는다.

## 실제 화면 검증

Chrome에서 날짜 이동, 국립공원 실제 현황, 이름 검색, 찜/해제, 저장 필터, 표/목록 전환을 확인했다.
약 520px 폭에서 목록·표의 페이지 가로 넘침이 없음을 확인했다. 최종 수정 후 로컬 화면을 다시 열어 미연결 목록 탐색과 안내를 확인했다.
실제 정보는 30분 후 만료되므로 압축본의 스냅샷도 시간이 지나면 미확인으로 표시되는 것이 정상이다.
최종 수집은 48/48곳 성공(46.4초). 갱신 직후 실제 화면에서 2026-10-21·2명 조건으로 빈자리 시설 46곳, 예약대기 시설 11곳 표시를 확인했다. 두 조건에 해당하는 시설은 중복될 수 있다.

## 압축본 검증

허용한 프로젝트 파일 35개와 해시 명세를 포함한다. ZIP 무결성, 각 파일 SHA-256, 세션·로그·Git·node_modules 제외를 확인했다.
별도 임시 폴더에 압축을 풀고 Python 모듈 컴파일, 별도 포트 서버 시작, 48개 국립공원 현황 API 응답을 검증했다. 검증 서버는 종료했다.

## 실제 휴양림 연동 검증

- [x] 제주 4곳 연속 조회 완료: 붉은오름 19객실, 서귀포 24객실, 교래 19객실, 제주절물 27객실. 성공 4, 실패 0.
- [x] 2026-10-18·2명 조건: 빈자리 시설 3곳, 예약대기 시설 0곳. 10월 19일로 이동 시 빈자리 시설 3곳, 대기 시설 4곳.
- [x] 다음 신청 순위 1·2 표시와 공식 화면 대1·대2 표시 확인. 개인 대기순번으로 표시하지 않음.
- [x] 실제 재조회 취소 시 작업 cancelled·완료 0, 기존 4개 시설 관측값 보존. 로컬 화면 중단 안내 확인.
- [x] 공식 탭 새로고침 후 로그인·세션 연결을 유지하고 조회 요청 대기 패널 복구.
- [x] 연결 직후 첫 검색이 목록 검색으로 끝나는 문제 수정 및 자동 회귀 검증.

전국 186곳·모든 월의 연속 수집이나 장시간 브라우저 종료 후 복구까지 검증한 것은 아니다. 로그인 만료·연결 지연·미지원 시설은 정상 상태로 추정하지 않고 미확인 또는 중단으로 처리한다.

원격 공개 배포나 저장소 푸시는 수행하지 않았다. 자동수집 워크플로 파일은 준비만 했고 일정을 활성화하지 않았다.
