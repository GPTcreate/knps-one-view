# 웹·개인 확장·운영자 수집기 검증 기록 · 2026-10-18

웹/API 버전과 독립 Chrome 확장을 별도 제품으로 운영한다. 이전 최종 1.0 판정은 일반 사용자용 배포까지 검증한 것으로 해석하지 않는다.

## 현재 자동 검증

Node 61개, Python 50개 총 111개 PASS. DOM 고정 자료는 테스트 안의 모의 응답이며 실제 빈자리로 배포하지 않는다.
- 검색·날짜·인원·정원·찜·목록/표·만료·알림과 악성 입력/링크 처리
- 웹에서 설치·로그인을 요구하지 않고 서버 공유 갱신을 요청하는 흐름, 기본 서버의 과거 개발 연결 API 비활성화
- 새 독립 확장의 기기 저장, 발신 탭 결합, 중복 수신, 조기 완료 거절, 취소·삭제 후 지연 응답 거절
- 서비스 워커 재생성 후 진행 보존, 연결 탭 닫힘 시 중단, 자체 화면 재사용, 큰 관측값의 저장 한도 처리
- 새 확장 콘텐츠 스크립트의 모의 2시설 조회·취소. 쿠키 접근 시 테스트 실패, 예약 버튼 클릭 0회
- 국립공원 수집 파싱·실패 보존·원자 저장, 공개 목록 갱신, 실행기, 서버의 호스트·출처·파일 접근 제한
- SQLite 시설·월 중복 제거·동시 요청·재시작 보존·최대 대기 한도·요청 빈도 제한
- 임대 만료·최대 실행 시간·제한 재시도·중지 후 늦은 응답 거절·같은 달 권위 있는 교체와 다른 달 시각 보존
- 별도 운영자 확장의 고정 전송 대상·인증·명시적 공유 동의·발신 탭 제한·서비스 워커 재시작 복구·업로드 필드 제한
- 임시 실제 HTTP 서버 + 운영자 워커 + 모의 공식 월별 DOM을 통한 웹 검색→수집→공유 대기 2순위 반영 통합 검증
- 완료 표시가 결과보다 앞서 도착해 웹의 주기적 확인을 멈추는 경합 수정 및 회귀 검증
- 공유 저장소 장애에도 국립공원 제공 유지·개인용/웹 개인정보 안내 분리

JavaScript 문법·Prettier 서식을 검사한다. 독립 ZIP은 허용 파일, manifest·참조 자산, PNG 크기, JavaScript 컴파일과 무결성을 확인한다.
3종 ZIP의 무결성·인증키 미포함·참조 자산·JavaScript 문법을 확인하고 웹 묶음의 파일별 SHA-256을 대조했다. 웹 ZIP을 별도 임시 폴더에 풀어 서버를 실행하고 제주 4곳 갱신 접수·오프라인 대기·빈 관측 결과·웹 개인정보 안내 제공을 확인한 뒤 검증 서버를 종료했다. 운영자 키·연결 설정·공유 SQLite는 배포 묶음에서 제외한다. 개인용 확장은 서버 업로드 기능 없이 기기 저장을 유지한다.

## 실제 브라우저 증거

- 2026-10-17 기존 개발 연결 도구로 제주 4개 휴양림 89객실의 공식 표시값을 수집했다. 날짜 이동·빈자리·대기순위, 취소와 공식 탭 재연결을 확인했다.
- 국립공원 48곳 실제 수집 성공, 날짜·이름 검색·찜·표/목록과 약 520px 화면 가로 넘침을 확인했다.
- 웹 변경 후 Chrome에서 ‘웹 미리보기’, 설치/로그인 불필요 안내, 숨겨진 연결 버튼을 확인했다.
- 2026-10-18 국립공원 현황 48/48곳 갱신 성공(46.2초). 확장과 별개인 웹 서버 현황으로 제공한다.
- 최신 로컬 웹을 재시작한 뒤 Chrome에서 제주 검색과 날짜 이동의 갱신 대기 4곳 표시를 확인했다. 같은 달 날짜 이동으로 요청 수가 늘지 않았다. 현재 수집기 미설치로 실관측 업로드는 진행하지 않았다.

새 독립 패키지의 Chrome 실설치 검증은 별도 항목이다. 이전 도구의 증거를 새 패키지의 실제 설치 검증으로 대체하지 않는다.
