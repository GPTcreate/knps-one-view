# 웹 공유 현황 · 운영자 수집기 사용법

2026-10-18 구현. 현재 로컬 시험 운영이며 외부 공개 서버·공식 API 연계·웹스토어 게시를 완료한 상태는 아니다.

## 실행 순서

일반 방문자는 웹 주소로 접속한다. Python과 확장을 설치하는 사람은 운영자뿐이다.

1. 소스 폴더의 **`start-operator.cmd`를 더블클릭**한다. 웹 실행·운영자 설정 생성·수집기 빌드·연결 점검을 한 번에 처리한다. 명령행에서는 `python prepare_operator.py`이며 브라우저 없이 준비하려면 `python prepare_operator.py --no-browser`다.
2. `.runtime/operator-connection.json`이 생성된다. 인증키가 들어 있으므로 다른 사용자에게 보내거나 웹에 올리지 않는다. 설정 파일 경로만 화면에 표시한다.
3. 빌드된 `artifacts/operator-extension`은 개인용 확장과 다른 패키지다. 다른 폴더에서 실행한 서버와 인증이 맞지 않으면 준비를 중단하며 그 프로세스를 임의로 종료하지 않는다.
4. Chrome 확장 관리에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**로 `artifacts/operator-extension` 폴더를 선택한다. 이미 설치했다면 다시 로드한다.
5. ‘숲자리 운영자 수집기’ 아이콘을 눌러 연결 설정 파일로 2번 JSON을 선택한다. 관측 결과 공유 체크 후 ‘숲나들e 연결·수집 시작’을 누른다.
6. 열린 숲나들e 공식 탭에서 직접 로그인한다. 기존 로그인 연결이 유효하면 그대로 사용할 수 있다. 수집 중에는 이 탭의 지역·시설·월을 직접 변경하지 않는다.
7. 웹에서 제주 등 작은 범위와 체크인 날짜·인원을 선택하고 ‘자리 찾아보기’를 누른다. 운영자는 공식 화면을 확인하고 웹은 새 관측 결과를 5초 간격으로 반영한다.
8. 수집기 화면의 업로드 수와 웹의 확인 시각·실제 객실·다음 대기 신청 순위를 공식 화면과 대조한다. 중지 버튼이나 공식 탭 닫기로 수집을 멈춘다.

브라우저 확장 관리 화면은 사용자가 직접 조작해야 하므로 새 수집기의 실제 설치·로그인·실조회 검증은 아직 남아 있다. 자동 테스트의 모의 공식 화면을 실제 빈자리 데이터로 배포하지 않는다.

## 작동 기준

- 웹 요청 날짜 범위는 한국 날짜 기준 오늘부터 90일이다. 이는 검색 범위이며 해당 기간의 예약 개방을 보장하지 않는다.
- 조회·날짜 이동·새로 확인은 시설·월 단위로 중복을 합친다. 최근 5분 이내 해당 월을 확인했다면 추가 작업을 만들지 않는다.
- 표시 단위는 1박이다. 월별 공식 표를 읽어 같은 달 날짜 이동에 재사용한다. 연박을 탐색하지 않는다.
- 수집기 연결이 없으면 ‘갱신 대기’를 표시한다. 로그인 만료·공식 조회 실패 시 기존 자료를 보존한다. 최대 3회 재시도 후 잠시 제한한다.
- 작업 임대는 120초이며 정상 하트비트로 연장하되 한 작업은 최대 5분이다. 중지·만료된 작업의 늦은 결과는 공유 현황을 덮어쓰지 못한다.
- 성공 관측은 같은 달 결과를 교체한다. 다른 달은 날짜별 원래 시각을 보존한다. 30분을 넘긴 자료는 현재 빈자리·매진으로 확정하지 않는다.
- 전체 대기 작업 최대 512개, 한 IP의 검색 요청은 분당 60회다. 로컬 소규모 시험 정책이며 공개 배포 전 부하·제공 조건에 맞게 조정한다.

## 저장과 인증

운영 상태를 확인하려면 `python maintenance.py doctor`를 실행한다. 서버·운영자 인증·저장소·관측 시설 수·연결 여부만 표시하며 인증키는 출력하지 않는다. `python maintenance.py backup`은 사용 중인 SQLite의 일관된 백업을 `.runtime/backups/`에 만들고 무결성을 검사한다. 기존 백업 파일은 덮어쓰지 않는다. 이 백업은 관측·대기열용이며 인증키와 연결 설정은 별도로 안전하게 보관해야 한다. 복구는 서버를 중지한 뒤 현재 DB와 WAL/SHM 파일을 별도 보존하고 검증된 백업을 `shared.sqlite3`로 복사해 시작한다.

`.runtime/shared.sqlite3`에 대기열과 공유 관측, 수집기 연결 상태를 저장한다. 서버를 다시 켜도 유지된다. `.runtime/operator.key`는 운영자 인증키이며 반복 설정 실행으로 바뀌지 않는다. `.runtime` 파일은 정적 웹으로 다운로드할 수 없고 모든 배포 ZIP에서 제외한다.

운영자 확장은 빌드 시 지정한 한 서버로만 업로드한다. 키는 ZIP에 넣지 않고 로컬 설정 파일에서 가져와 확장의 신뢰된 저장소에 보관한다. 상태 화면·웹 응답·URL에 키를 넣지 않는다. 계정·쿠키·비밀번호·개인 예약 내역을 읽거나 업로드하지 않는다. 전송 필드는 시설·객실·정원·날짜·예약 상태·다음 대기 신청 가능 순위·확인 시각이다.

개인용 확장 `artifacts/chrome-extension`은 공유 수집과 별개다. 기기에 저장하며 서버 업로드 권한이나 운영자 키가 없다. 두 확장을 같은 공식 탭에서 동시에 실행하지 않는다.

## 외부 공개 전 남은 일

현재 Python 서버는 루프백 주소만 허용한다. `--server` 옵션은 향후 고정 HTTPS 전송 대상을 빌드·설정할 수 있게 준비한 기능이며 원격 배포를 수행하지 않는다.

외부 배포에는 HTTPS 운영 환경, 실제 도메인과 출처 설정, 요청 제한·모니터링, 운영자 키 관리, 데이터 공유·재제공 허용 범위 확인이 필요하다. 로그인 탭이 필요한 운영자 수집기로 24시간 전국 실시간을 약속하지 않는다. 공식 API 승인·명세가 확보되면 수집 경로를 교체한다.

스토어에 제출하는 것은 개인용 확장이다. 운영자 수집기 ZIP과 연결 설정 파일을 개인용 스토어 패키지에 섞지 않는다. 개발자 계정·실설치 검증·등록 자료·심사는 별도 진행 항목이다.
