# 숲자리 1.0 기획 검토 · 개발 기준

## 사용자 문제와 확정 방향

여러 휴양림 홈페이지와 달력을 각각 열어 빈자리와 예약대기를 찾기 어렵다.
숙박·항공 예약 사이트처럼 지역, 날짜, 인원으로 검색하고 여러 시설의 실제 상태를 비교한다.
날짜를 앞뒤로 빠르게 이동하며 기회를 탐색한다. 조회 단위는 1박이며 연박 기능은 제외한다.
국립공원 야영장은 같은 방식으로 제공하되 휴양림 탐색을 첫 화면으로 둔다.

## 데이터 연동의 현재 증거

- 2026-10-17 숲나들e 공식 공개 지역/시설 목록: 9개 권역, 186개 시설.
- 공식 월별현황 페이지는 비로그인 서버 요청에 HTTP 401 응답. 공개 시설 목록을 잔여현황으로 해석하지 않는다.
- 국립공원 공식 공개 야영장 현황 응답에서 객실별 날짜와 예약/대기/마감/종료 상태를 확인했다.
- 로그인된 Chrome에서 유명산 54개 실제 객실의 날짜별 예약·대기 표시를 확인했다. 연결 도구를 통한 여러 시설 연속 수집을 검증하기 전에는 전체 연동 완료로 판정하지 않는다.
- 개인정보·로그인 쿠키를 저장소나 웹페이지에 넣지 않는다. 자동 예약·대기 신청은 범위 밖이다.

## 최종 검증 기준

실제 응답 수집, 정보 누락과 실패 분리, 날짜 및 인원 필터, 실제 대기순위의 의미 구분,
찜 유지, 날짜 이동, 모바일 화면, 오류/빈 결과/부분 실패, 상태변화 알림을 검증한다.
웹 화면 완성도와 숲나들e 실제 연동 완료 여부를 별도로 보고한다.
