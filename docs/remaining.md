# 숲자리 1.0 출시 인계 · 2026-10-19

웹·개인용 확장과 내부 운영자 수집기는 구현했으며 현재 로컬 시험 범위다. 자동 테스트와 ZIP 검증은 실제 새 확장 설치·로그인 증거를 대신하지 않는다.

## 지금 실행할 것

프로젝트 폴더에서 `start-operator.cmd`를 실행하면 웹 실행·인증 설정·운영자 확장 빌드·연결 확인을 처리한다. 일반 방문자는 이 절차를 수행하지 않는다.

1. Chrome 확장 관리에서 `artifacts/operator-extension` 폴더를 직접 로드한다.
2. 운영자 수집기 화면에서 `.runtime/operator-connection.json`을 선택하고 공유 체크 후 수집을 시작한다.
3. 열린 숲나들e 공식 화면에서 직접 로그인한다.
4. 웹에서 제주·가까운 날짜·전체 상태로 검색한다. 빈자리가 없어도 객실·상태·확인 시각을 공식 화면과 대조할 수 있다.
5. 운영자 실조회 확인 후 수집을 중지하고 `artifacts/chrome-extension`으로 개인용 확장을 별도 검증한다.

같은 공식 탭을 두 수집 확장에서 동시에 조작하지 않는다. 이전 `browser-bridge`는 과거 개발 검증 도구이며 새 설치 대상으로 사용하지 않는다.

## 이미 준비한 것

- 검색·날짜 탐색·인원·찜·객실·대기 신청 기회 비교
- 웹 갱신 대기열, 시설·월 중복 제거, 임대·제한 재시도·늦은 응답 차단
- 개인용 확장 기기 저장과 별도 운영자 인증·공유 업로드
- 같은 달 재조회에서 사라진 객실·날짜 제거, 다른 달의 원래 확인 시각 유지
- 저장소 장애 시 화면의 직전 관측 보존과 장애 안내
- 실행 준비, 상태 진단, SQLite 일관 백업과 무결성 확인
- ZIP 허용 파일·참조·문법·체크섬·실제 로컬 인증키 제외 자동 검증
- GitHub Actions 테스트·빌드·검증 후 웹/개인용 확장 ZIP 다운로드
- 등록 소개·개인정보 안내·심사 설명·공식 API 및 공유 허용 문의 초안

## 외부 입력과 실제 확인이 남은 것

| 항목 | 필요한 조치 | 완료 증거 |
| --- | --- | --- |
| Chrome 실설치 | 소유자가 새 확장 설치, 공식 로그인 | 여러 시설 실조회·중단·재연결·삭제 및 웹 공유 대조 |
| 스토어 계정 | 소유자가 개발자 등록·약관·비용 처리 | 개발자 대시보드 접근 |
| 등록 정보 | 개발자 표시 이름·지원 이메일 확정 | 확정된 등록 문안·공개 개인정보 URL·실제 스크린샷 |
| 데이터 제공 조건 | 조회 전용 API와 운영자 수집 후 공유 허용 범위 문의 | 기관 회신·허용 조건 |
| 공개 웹 환경 | 운영 주체·도메인·호스팅 계정·비용과 운영 범위 결정 | HTTPS 서버에서 인증·갱신·복구·부하 검증 |
| 공식 API 경로 | 가능 회신 후 승인·명세·인증키 확보 | 실제 응답 필드·대기 순위·범위 대조 |
| 출시 | 실검증과 심사·제공 조건을 반영 | 공개 웹 주소·스토어 설치 URL |

공개 웹 서버 구성과 실배포는 아직 완료되지 않았다. 현재 서버는 루프백 전용이다. 도메인·호스팅 결정 후 배포 코드와 실제 운영 검증을 이어가야 하며, 별도 비용·계정·데이터 권한을 임의로 확정하지 않았다. API 승인 전에도 개인용 확장 실검증·스토어 준비는 병행한다.

## 운영 명령

```powershell
python prepare_operator.py --no-browser
python maintenance.py doctor
python maintenance.py backup
```

개발 검증은 `npm run check`, `npm run format:check`, `npm test`, `python -m unittest discover -s tests -p "test_*.py" -v`다. 묶음은 `python build_extension.py`, `python build_operator.py`, `python build_release.py` 후 `python verify_release.py --syntax`로 확인한다.

GitHub Actions의 Validate Forest Seat 실행에서 `forest-seat-tested-packages`를 받으면 웹·개인용 확장 ZIP과 SHA-256 파일이 들어 있다. 내부 운영자 ZIP·설정·키·실행 DB는 Actions 다운로드 묶음에 넣지 않는다. 국립공원 수집 워크플로는 수동 실행만 준비했으며 예약 실행은 켜지 않는다.
