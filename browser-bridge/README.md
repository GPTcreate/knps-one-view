# 숲자리 공식현황 연결 도구

이 Chrome 확장프로그램은 사용자가 로그인한 숲나들e의 월별 조회 화면을 정상적으로 조작하고,
화면에 표시된 객실명·날짜·예/대1/대2/대3/완/휴/공/우/추 표시만 읽어 로컬 숲자리로 전달합니다.

## 접근 범위

- 숲나들e: 공식 월별 조회 화면에서 지역·시설·숙소·월을 선택하고 검색합니다.
- 로컬 서버: 코드에 고정된 http://127.0.0.1:8765의 연결·진행·결과 API만 호출합니다.
- 쿠키, 비밀번호, 계정 이름, 개인 예약 내역을 읽거나 전송하는 코드는 없습니다.
- 예약 신청·대기 신청·결제 버튼을 누르지 않습니다. 검색 버튼만 사용합니다.
- CAPTCHA나 로그인 요구가 나타나면 사용자가 직접 처리해야 합니다.
- 전달되는 연결 키는 로컬 서버 재시작 때 변경되고 세션 저장소에만 둡니다.
- 모든 수집 자료는 .runtime/forest-status.json에 저장되며 Git 추적에서 제외됩니다.

## 설치 (사용자가 권한 범위를 확인한 뒤)

1. Chrome의 chrome://extensions 를 엽니다.
2. 개발자 모드를 켜고, '압축해제된 확장 프로그램을 로드합니다'를 선택합니다.
3. 이 README가 있는 browser-bridge 폴더를 선택합니다.
4. 숲자리 로컬 화면의 '공식 현황 연결'을 누릅니다.
5. 숲나들e 로그인을 마치고 연결 탭을 열어 둡니다.
6. 숲자리에서 지역과 날짜를 선택하고 '자리 찾아보기'를 누릅니다.

조회 중에는 연결된 숲나들e 탭의 검색 조건을 직접 바꾸지 마세요.
지역을 선택하면 해당 지역 전체를 비교합니다. 전국 조회는 시설 수에 따라 오래 걸릴 수 있습니다.
미조회 시설, 숙소 미지원 시설, 조회 실패, 표시되지 않은 날짜는 미확인으로 남깁니다.
인원 기준 숫자가 최대 정원이라고 단정하지 않습니다. 공식 화면의 기준 인원은 별도 표시합니다.

## 검토할 파일

- manifest.json: 요청하는 사이트 접근 범위
- content.js: 공식 화면 조작과 조회 순서
- extractor.js: 표시값의 정규화. 개인 대기순번을 읽지 않습니다.
- background.js: 로컬 연결 허용 경로 3개만 중계

개발 코드 설치 권한 확인과 실제 Chrome 연결 검증이 끝나기 전에는 전체 1.0 완료로 판정하지 않습니다.
