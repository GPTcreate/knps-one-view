# 숲자리 1.0

여러 자연휴양림과 국립공원 야영장의 빈자리·예약대기 기회를 한 화면에서 비교하는 웹앱입니다.
지역·체크인 날짜·인원으로 검색하고, 일주일 날짜 띠에서 다른 날짜를 탐색합니다.
조회는 1박 기준입니다. 연박 필터는 제공하지 않습니다.

## 현재 검증 범위

- 숲나들e 공개 목록: 9개 권역, 186개 시설. 시설 목록과 예약현황은 서로 다릅니다.
- 국립공원: 공식 공개 현황에서 48개 야영장 실제 객실·영지 상태 수집 검증.
- 숲나들e 잔여·예약대기: 로그인된 공식 화면에서 유명산 54객실의 실제 표시값 확인. 연결 도구 설치 후 여러 시설 연속 조회 검증이 남아 있습니다.
- 순위가 없는 공식 예약대기 응답에 신청 순위를 임의로 붙이지 않습니다.
- 개인의 대기순번과 객실의 대기 신청 가능 순위는 서로 다른 정보입니다.

## 실행

Python 3.10 이상과 모던 브라우저가 필요합니다. 웹 실행에 npm 설치는 필요하지 않습니다.

```powershell
python server.py
# http://127.0.0.1:8765
```

파일 더블클릭 대신 로컬 서버를 사용합니다. 서버는 127.0.0.1에만 연결하며 명시한 공개 파일만 제공합니다.
원본 파일은 작업 전 백업되었습니다. 작업 브랜치: develop/v1.0-20261017.

## 국립공원 현황 수집

```powershell
python scraper_real.py
```

최대 2개의 요청을 병렬 수행합니다. 정상 응답의 날짜별 예약·대기·마감·종료 아이콘을 파싱합니다.
모든 시설 조회가 실패하면 기존 스냅샷을 보존하고 실패합니다. 부분 실패 시 시설별 과거 확인 시각을 유지합니다.
저장은 임시 파일과 원자적 교체를 사용합니다.

## 신뢰성과 알림

시설별 관측 시각이 30분을 넘으면 현재 빈자리나 대기라고 표시하지 않습니다.
누락된 날짜는 매진과 구분해 미확인으로 처리합니다. 공개 정원 정보가 없으면 미제공으로 표시합니다.
변화 알림은 이 화면이 열려 있는 동안 저장한 시설의 동일 객실 관측값을 비교합니다.
초기 조회, 날짜·인원 변경, 오래된 자료, 동일 관측값 반복에는 알리지 않습니다.
예약과 대기 신청은 공식 사이트에서 사용자가 직접 진행합니다.

## 검증

```powershell
node --test tests/core.test.js tests/extractor.test.js
python -m unittest discover -s tests -p "test_*.py" -v
node --check app.js
node --check core.js
```

기획 검토와 범위: [docs/1.0-review.md](docs/1.0-review.md).
기존 status.json 및 진단 스크립트는 이전 구현 자료이며 1.0 화면의 현황 소스로 사용하지 않습니다.
로그인 쿠키나 비밀번호를 코드·JSON·GitHub Actions에 넣지 마세요.

## 배포

정적 배포 시 availability.json과 catalog.json을 함께 제공합니다. 국립공원 자동 수집 워크플로는 별도 구성입니다.
로컬 로그인 세션이 필요한 숲나들e 조회를 GitHub Actions에서 자동 실행할 수 있다고 가정하지 않습니다.
현재 단계에서는 원격 저장소 반영이나 공개 배포를 수행하지 않았습니다.

## 숲나들e 로그인 연결

[연결 도구 설치 및 접근 범위](browser-bridge/README.md)를 확인하세요.
Chrome 확장 관리 화면은 브라우저 도구의 보안 정책으로 자동 접근할 수 없어 사용자가 직접 설치해야 합니다.
연결 도구는 공식 화면의 검색만 조작하고 표시된 잔여·대기 정보만 로컬로 전달합니다.
비밀번호·쿠키·개인 예약 내역은 읽지 않습니다.
설치 후 로컬 앱의 공식 현황 연결을 누르고 로그인된 연결 탭을 열어 둔 채 검색합니다.
기본은 선택 지역 전체 조회이며, 저장한 곳만 필터가 켜져 있으면 해당 시설만 조회합니다.
