# 숲자리 1.0 RC

여러 자연휴양림과 국립공원 야영장의 빈자리·예약대기 기회를 한 화면에서 비교합니다.
숙박 예약사이트처럼 지역·체크인 날짜·인원으로 검색하고 일주일 날짜 띠에서 다른 날짜를 탐색합니다.
조회 단위는 1박입니다. 연박 기능은 제공하지 않습니다.

## 바로 실행

Python 3.10 이상과 최신 브라우저가 필요합니다. Windows에서는 **start.cmd**를 더블클릭합니다.
웹앱 실행에 npm 설치는 필요하지 않습니다.

```powershell
python launcher.py
# http://127.0.0.1:8765
```

실행기는 기존 숲자리 서버를 재사용하고, 없으면 숨김 서버를 시작한 뒤 브라우저를 엽니다.
다른 프로그램이 포트를 사용하면 종료하지 않고 안내합니다. 브라우저 없이 시작하려면 `--no-browser`를 추가합니다.
서버 로그는 `.runtime/server.log`에 저장합니다. 직접 실행·종료하려면 `python server.py`를 사용합니다.
연결 도구는 기본 포트 8765를 사용합니다. 정적 파일 더블클릭 대신 로컬 서버로 실행하세요.

## 기능과 데이터 범위

- 자연휴양림 공식 목록 186곳, 9개 권역. 로그인 연결 전에도 시설·지역·운영 구분·이름·찜 검색 가능.
- 국립공원 야영장 48곳의 공식 공개 객실·영지 현황 수집과 빈자리·예약대기 비교.
- 날짜 이동, 예약 기회 우선 정렬, 목록·표 보기, 객실 펼치기, 찜 유지, 저장한 곳 필터.
- 진행률·취소·연결 중단·부분 실패 처리. 빠르게 조건을 바꿔도 마지막 검색 결과를 유지.
- 로그인된 공식 화면에서 유명산 54객실의 표시값 확인. 연결 도구를 통한 여러 휴양림 실제 연속 조회는 사용자 요청으로 추후 검증.

시설 목록과 실제 잔여현황은 다릅니다. 미연결 상태에서는 조회 작업을 대기열에 쌓지 않습니다.
확인하지 못한 현황은 매진·빈자리로 추정하지 않습니다.
숲나들e 대1/대2/대3은 **다음 대기 신청 순위**이며 개인 대기순번이 아닙니다.
순위가 없는 공식 예약대기 응답에는 순위를 붙이지 않습니다.

## 최신 현황 수집

```powershell
python scraper_real.py
python refresh_catalog.py
```

첫 명령은 국립공원 공개 예약현황, 둘째는 숲나들e 공개 시설 목록만 갱신합니다.
국립공원은 최대 2개 요청을 병렬 수행합니다. 전체 실패 시 기존 파일을 보존하고, 부분 실패한 시설은 이전 관측 시각을 유지합니다.
저장은 임시 파일과 원자적 교체를 사용합니다.
숲나들e 잔여현황은 [공식현황 연결 도구](browser-bridge/README.md)를 별도로 연결해야 합니다. 설치·실제 연동 검증은 현재 보류 중입니다.

## 신뢰성과 알림

날짜별 관측 시각이 30분을 넘으면 현재 빈자리나 대기로 표시하지 않습니다.
다른 달을 새로 수집해도 과거 날짜의 시각은 유지합니다. 누락·미확인·매진·휴무·우선예약·추첨을 구분합니다.
최대 정원 미제공 객실은 인원 필터 결과에 포함하며 이를 표시합니다. 기준 인원을 최대 정원으로 간주하지 않습니다.
변화 알림은 화면이 열려 있는 동안 저장한 시설의 동일 객실에서 새로 관측된 변화를 비교합니다.
초기 조회, 날짜·인원 변경, 만료 자료, 동일 관측값 반복에는 알리지 않습니다. 화면을 닫은 뒤 백그라운드 알림은 제공하지 않습니다.
예약·대기 신청은 공식 사이트에서 직접 진행합니다.

## 개발 검증

Node.js 24.15 이상이 필요합니다. npm 의존성은 개발 검증에만 사용합니다.

```powershell
npm ci --ignore-scripts
npm run check
npm run format:check
npm test
python -m unittest discover -s tests -p "test_*.py" -v
```

기획 기준: [docs/1.0-review.md](docs/1.0-review.md). 검증 결과: [docs/1.0-validation.md](docs/1.0-validation.md).
DOM 검증의 고정 응답은 테스트 안의 모의 자료이며 운영 데이터로 사용하지 않습니다.
기존 `status.json` 및 이전 진단 스크립트는 1.0 현황 소스로 사용하지 않습니다.

## 배포용 압축본

```powershell
python build_release.py
```

`artifacts/forest-seat-1.0-rc.zip`과 SHA-256 검증 파일을 생성합니다.
허용 목록의 소스·공개 현황·연결 도구·문서·테스트만 포함하고 `.runtime`, 로그인 자료, `.git`, `node_modules`는 제외합니다.
압축 해제 후 `start.cmd`로 실행합니다. 실제 휴양림 연동 검증 전까지 RC 표시를 유지합니다.
원격 저장소 반영·공개 배포·자동수집 일정 활성화는 수행하지 않았습니다.
국립공원 자동수집 워크플로 파일은 준비되어 있으며 숲나들e 로그인 세션을 원격 자동수집에 사용하지 않습니다.

서버는 127.0.0.1에만 연결하고 허용한 공개 파일만 제공합니다. 로그인 쿠키·비밀번호를 코드·JSON·GitHub Actions에 넣지 마세요.
